Open source contributions to this library are welcome, both new features and improvements to existing ones. The library was originally designed to fill the gaps in my digital landscape photography workflow over the last 10 to 15 years: things I wished there was software to help me do. If there are parts of your workflow you would also like to automate, feature requests are welcome too.

### Contributing Code
Follow the standard process: fork the repository and open a pull request. This applies to bug fixes, optimizations, and new features.

### Requesting Features
If you would like to see a new feature that would help your own workflow, feel free to suggest it by opening a feature request issue. If you are able to write the code for it, either on your own or with the help of AI coding agents, that is also welcome.

### Development Setup
The build instructions are provided [here](BuildInstructions.md). If any part is unclear and you would like to help make it clearer, feel free to open a pull request.
